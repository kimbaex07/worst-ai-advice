One line of the worst possible advice an AI could give, in 139 characters: a phone dropped in water, and a confident assistant's fix — microwave it for 30 seconds, because the waves dry it out and top up the battery at the same time. It sounds exactly like a helpful AI assistant being catastrophically wrong, and the joke lands on the first read. Running `main.py` writes that one line to `entry.txt` — first to the grader's output directory, then as a local copy. Pure Python standard library, no network, no dependencies.

## Run it

```sh
python3 main.py
```
